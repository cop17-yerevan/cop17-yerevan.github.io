# Yerevan COP17 Road Closures

Interactive day-by-day map of street closures in Yerevan during COP17 (UN Biodiversity Conference, 19–30 October 2026).

**Live map:** https://cop17-yerevan.github.io/

- Confirmed days come from Armenian police notices as reported by Armenpress, NT.am and other outlets. Sources are linked on each day.
- Days not yet announced show a forecast based on earlier COP17 notices, drawn with dashed lines.
- Street data © OpenStreetMap contributors (ODbL).

Updated daily during the conference.
